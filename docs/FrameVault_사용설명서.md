# FrameVault V1.0.0 사용 설명서

FrameVault는 USB 카메라, 메모리카드 또는 일반 폴더에 있는 사진과 영상을 로컬 폴더, SMB 공유 또는 HTTPS WebDAV 저장소로 증분 백업하는 Windows 프로그램입니다.

증분 백업은 대상에 이미 있는 정상 파일을 건너뛰고 새 파일과 누락된 파일을 전송하는 방식입니다. 백업 파일은 촬영일에 따라 `연도/월` 폴더로 정리됩니다.

## 1. 실행 전 준비

### 시스템 요구사항

- 64비트 Intel 또는 AMD 기반 PC
- Windows 10 버전 1809 이상 또는 Windows 11
- 원본을 읽고 백업 대상에 쓸 수 있는 권한
- SMB 또는 WebDAV 사용 시 대상 저장소에 연결할 수 있는 네트워크

### 포터블 버전 실행

1. 배포 ZIP 파일의 압축을 완전히 풉니다.
2. 압축을 푼 폴더의 최상위에 있는 `FrameVault.exe`를 실행합니다.
3. 같은 위치의 `app` 폴더를 이동하거나 삭제하지 않습니다.

```text
FrameVault-v1.0.0-win-x64/
├─ FrameVault.exe       ← 이 파일을 실행
├─ app/                 ← 실행에 필요한 파일
└─ docs/                ← 설명서
```

Windows가 처음 실행을 차단하면 파일의 출처와 배포처를 확인하십시오. 현재 포터블 배포본은 공인 코드 서명이 없어 Windows SmartScreen 또는 Smart App Control 정책에 따라 실행이 제한될 수 있습니다.

## 2. 화면 구성

FrameVault의 설정 순서는 화면 위에서 아래 방향입니다.

1. **백업 대상 프로필**: 자주 사용하는 저장 위치와 접속 설정을 저장하거나 불러옵니다.
2. **원본**: 카메라, 메모리카드 또는 사진 폴더를 선택합니다.
3. **촬영 기간**: 백업할 사진과 영상의 촬영 기간을 제한합니다.
4. **백업 대상 종류**: 로컬, SMB, WebDAV 중 저장 방식을 선택합니다.
5. **대상 경로와 계정**: 실제 저장 위치와 필요한 접속 정보를 지정합니다.
6. **원격 검증**: 표준 또는 정밀 검증을 선택합니다.
7. **자동백업 임시파일 경로**: WPD 카메라 작업에 사용한 임시 파일을 관리합니다.
8. **작업 버튼**: 연결 시험, 새 파일 백업, 전체 무결성 검사, 취소를 실행합니다.
9. **진행 표시**: 진행률, 처리 파일 수, 작업 결과를 표시합니다.

오른쪽 위의 **화면 테마** 스위치로 화이트 모드와 다크 모드를 바꿀 수 있습니다.

## 3. 가장 빠른 사용 순서

1. 카메라 또는 메모리카드를 PC에 연결합니다.
2. **자동 탐색**을 눌러 원본을 선택합니다.
3. **백업 대상 종류**에서 저장 방식을 선택합니다.
4. 백업 대상 경로와 필요한 계정 정보를 입력합니다.
5. SMB 또는 WebDAV라면 **연결 후 폴더 선택**으로 저장할 하위 폴더를 고릅니다.
6. **연결 시험**을 눌러 접근 권한을 확인합니다.
7. 반복해서 사용할 설정이라면 이름을 입력하고 **프로필 저장**을 누릅니다.
8. **새 파일 백업**을 누릅니다.
9. 상태가 완료로 바뀔 때까지 카메라, 카드, 네트워크 연결을 유지합니다.

## 4. 원본 선택

### USB 카메라 자동 탐색

1. 카메라를 켜고 USB로 PC에 연결합니다.
2. 카메라가 연결 방식을 묻는다면 PTP 또는 MTP를 선택합니다.
3. FrameVault에서 **자동 탐색**을 누릅니다.
4. 장치가 여러 개면 표시되는 목록에서 백업할 장치를 선택합니다.

WPD/MTP/PTP 카메라는 일반 드라이브 문자 대신 Windows 휴대용 장치로 표시될 수 있습니다. FrameVault는 장치 내부의 사진 폴더를 찾아 **원본**에 적용합니다.

카메라를 분리했다가 다시 연결하여 Windows 장치 ID가 바뀐 경우, 연결된 WPD 카메라가 한 대라면 백업 시작 시 새 ID를 자동으로 적용합니다.

### 메모리카드와 외장 드라이브 자동 탐색

카드 리더기에 메모리카드를 넣은 뒤 **자동 탐색**을 누릅니다. FrameVault는 `DCIM` 폴더와 지원되는 미디어 파일을 기준으로 원본 후보를 찾습니다.

### 폴더 직접 선택

USB 장치가 자동으로 발견되지 않거나 PC의 기존 폴더를 백업하려면 **폴더 선택**을 누르고 원본 폴더를 직접 고릅니다.

### 자동 장치 감지

**5초마다 새 카메라나 카드 연결을 감지**가 켜져 있으면 프로그램 시작 시 한 번 확인하고 이후 5초마다 새 장치를 확인합니다.

- 새 장치를 찾으면 즉시 **원본**에 반영합니다.
- 저장된 프로필이 있으면 사용할 프로필을 고른 뒤 바로 백업할 수 있는 창이 열립니다.
- **나중에**를 눌러도 감지된 장치는 원본으로 유지됩니다.
- 이전부터 연결되어 있던 장치가 다시 제안되지 않으면 **자동 탐색**을 눌러 수동으로 갱신합니다.

## 5. 촬영 기간 지정

**촬영 기간**의 시작일과 종료일을 지정하면 해당 기간에 촬영된 파일만 백업하거나 검사합니다.

- 두 날짜를 모두 비우면 전체 기간을 처리합니다.
- 시작일만 지정하면 그 날짜 이후 파일을 처리합니다.
- 종료일만 지정하면 그 날짜까지의 파일을 처리합니다.
- 시작일과 종료일은 모두 포함됩니다.
- 시작일은 종료일보다 늦을 수 없습니다.

파일에 촬영일 메타데이터가 없으면 FrameVault가 확인할 수 있는 파일 날짜를 기준으로 분류할 수 있습니다.

## 6. 백업 대상 설정

### 로컬 폴더 또는 외장 드라이브

1. **백업 대상 종류**에서 **로컬 폴더 / 외장 드라이브**를 선택합니다.
2. **경로 선택**을 누르고 저장할 폴더를 고릅니다.
3. 화면의 **실제 사진 저장 경로 예시**가 의도한 위치인지 확인합니다.
4. **연결 시험**을 누릅니다.

로컬 백업은 선택한 원본에서 대상 폴더로 직접 복사합니다. 네트워크 계정은 사용하지 않습니다.

예시:

```text
D:\FrameVaultBackup\2026\10\DSC_0001.NEF
```

### SMB 네트워크 공유

1. **백업 대상 종류**에서 **SMB 네트워크 공유**를 선택합니다.
2. **백업 대상 루트**에 공유 경로를 입력합니다.
3. 대상에 접근할 계정과 비밀번호를 입력합니다.
4. **연결 후 폴더 선택**을 누릅니다.
5. 로그인 후 표시되는 폴더 트리에서 저장할 폴더를 선택합니다.
6. **연결 시험**을 누릅니다.

SMB 루트 예시:

```text
\\diskstation\photo
```

Windows에 같은 서버의 다른 계정으로 열린 SMB 세션이 있으면 인증 충돌이 발생할 수 있습니다. 이 경우 기존 Windows 네트워크 연결을 정리하거나 동일한 계정을 사용하십시오.

### HTTPS WebDAV

1. **백업 대상 종류**에서 **HTTPS WebDAV**를 선택합니다.
2. **백업 대상 루트**에 WebDAV 루트 URL을 입력합니다.
3. 계정과 비밀번호를 입력합니다.
4. **연결 후 폴더 선택**을 누릅니다.
5. 로그인 후 표시되는 폴더 트리에서 저장할 폴더를 선택합니다.
6. **연결 시험**을 누릅니다.

WebDAV 주소 예시:

```text
https://nas.example.com:5006/photo
```

FrameVault는 HTTPS WebDAV 주소만 허용합니다. 인증서 오류가 발생하면 NAS의 인증서, 주소, 유효기간 및 PC 시간을 확인하십시오.

### 저장 경로 확인

백업 파일은 선택한 대상 폴더 아래에 촬영 연도와 월별로 저장됩니다.

```text
선택한 대상/
├─ 2025/
│  ├─ 01/
│  └─ 12/
└─ 2026/
   ├─ 01/
   └─ 10/
```

화면의 **실제 사진 저장 경로 예시**에서 루트, 선택한 하위 폴더, 연도/월 구조를 백업 전에 확인하십시오.

## 7. 프로필 사용

프로필은 백업 대상을 다시 입력하지 않도록 다음 항목을 함께 저장합니다.

- 로컬, SMB 또는 WebDAV 저장 방식
- 대상 루트와 선택한 하위 폴더
- 네트워크 계정과 비밀번호
- 표준 또는 정밀 검증 방식

원본 카메라나 메모리카드는 프로필의 고정 대상이 아닙니다. 새로 감지된 장치를 원본으로 사용하고, 프로필은 그 파일을 어디에 어떻게 저장할지를 결정합니다.

### 프로필 저장

1. 백업 대상 설정을 모두 마칩니다.
2. 네트워크 대상은 **연결 후 폴더 선택**까지 완료합니다.
3. 프로필 이름을 입력합니다.
4. **프로필 저장**을 누릅니다.

프로필은 최대 4개까지 저장할 수 있습니다. 같은 이름으로 저장하면 기존 프로필이 갱신됩니다.

### 프로필 불러오기와 삭제

- **프로필 선택** 목록에서 항목을 선택하면 저장 방식, 경로, 계정과 검증 방식이 화면에 적용됩니다.
- 필요 없는 프로필은 선택한 뒤 **프로필 삭제**를 누릅니다.

### 비밀번호 보호

저장된 비밀번호는 Windows DPAPI를 사용해 현재 Windows 사용자 범위에서 보호됩니다. 같은 사용자로 FrameVault를 다시 실행하면 저장된 프로필을 계속 사용할 수 있습니다. 다른 PC나 다른 Windows 사용자 계정으로 복사하면 비밀번호를 다시 입력해야 할 수 있습니다.

## 8. 검증 방식 선택

### 표준 — 파일 크기 확인

대상 파일의 존재 여부와 크기를 확인합니다. 속도가 빠르고 네트워크 사용량이 적어 평소 증분 백업에 적합합니다.

### 정밀 — 원격 파일 SHA-256 재검증

원본과 대상 파일의 SHA-256 해시를 비교합니다. 같은 크기이지만 내용이 달라진 파일도 확인할 수 있습니다.

- 로컬과 SMB 대상에서는 대상 파일을 읽어 해시를 계산합니다.
- WebDAV 서버가 SHA-256 정보를 제공하면 그 값을 사용할 수 있습니다.
- 서버가 해시 정보를 제공하지 않으면 대상 파일 내용을 네트워크로 읽어 해시를 계산합니다.
- 읽은 원격 파일은 별도의 전체 파일로 로컬 캐시에 저장하지 않지만, 네트워크 수신량과 읽기 작업은 파일 크기만큼 발생할 수 있습니다.

대용량 자료를 정밀 검증하면 시간이 오래 걸릴 수 있으므로 안정적인 네트워크에서 실행하십시오.

## 9. 새 파일 백업

1. 원본, 촬영 기간, 백업 대상과 검증 방식을 확인합니다.
2. 네트워크 대상이라면 폴더 선택과 **연결 시험**을 먼저 완료합니다.
3. **새 파일 백업**을 누릅니다.
4. 진행률과 `전송 완료` 파일 수를 확인합니다.
5. 완료 메시지가 표시될 때까지 원본과 대상을 분리하지 않습니다.

FrameVault는 이전 작업 기록과 실제 대상 파일을 함께 확인합니다. 이전에 백업한 파일이라도 대상에서 삭제되었으면 누락된 파일로 판단해 다시 전송합니다.

전송 중에는 불완전한 파일이 최종 파일로 보이지 않도록 임시 이름을 사용하고, 검증을 통과한 뒤 최종 이름으로 바꿉니다. 작업이 끊기면 `.part` 형태의 임시 파일이 남을 수 있으며, 다음 작업에서 정상 파일 여부를 다시 확인합니다.

같은 최종 경로에 이름은 같지만 내용이 다른 파일이 있으면 덮어쓰지 않고 충돌 오류를 표시합니다. 이 경우 원본과 대상 파일을 직접 확인하고 한쪽의 이름이나 위치를 정리한 뒤 다시 실행하십시오.

## 10. 전체 무결성 검사

**전체 무결성 검사**는 현재 선택한 원본과 백업 대상의 파일을 1대1로 비교하여 다음 문제를 찾습니다.

- 대상에 없는 파일
- 크기가 다른 파일
- SHA-256 해시가 다른 파일

검사는 파일을 추가, 수정 또는 삭제하지 않습니다. 결과 목록에는 `누락`과 `불일치` 항목이 표시됩니다.

전체 무결성 검사는 원본과 대상의 내용을 읽어 SHA-256을 비교하므로 표준 백업 대조보다 오래 걸립니다. WebDAV 서버가 해시 값을 제공하지 않으면 원격 파일을 네트워크 스트림으로 다시 읽습니다. 이 데이터는 완전한 파일 형태로 로컬 디스크에 저장하지 않습니다.

누락된 파일을 복구하려면 검사 후 **새 파일 백업**을 실행하십시오. 불일치 파일은 자동으로 덮어쓰지 않을 수 있으므로 충돌 내용을 먼저 확인하십시오.

## 11. 카메라 정보 확인

1. 카메라, 메모리카드 또는 사진 폴더를 원본으로 선택합니다.
2. **카메라 정보**를 누릅니다.
3. FrameVault가 가장 최근 사진을 찾아 메타데이터를 표시합니다.

표시 항목:

- 최근 촬영 일시
- 총 셔터수
- 카메라 기종
- 시리얼 번호
- 카메라 바디 제조일자
- 렌즈 제조사
- 렌즈 모델명
- 렌즈 스펙 정보

카메라 제조사, 기종 또는 파일 형식이 해당 값을 기록하지 않았거나 해석할 수 없으면 `N/A`로 표시됩니다. `N/A`는 카메라에 문제가 있다는 뜻이 아닙니다.

## 12. 자동백업 임시파일 관리

기본 임시파일 위치는 다음과 같습니다.

```text
%LOCALAPPDATA%\FrameVault\WpdCache
```

이 위치에는 이전 버전이나 중단된 작업에서 만든 WPD 카메라 임시 파일이 남아 있을 수 있습니다. 현재 버전의 새 검사와 백업은 WPD 카메라 파일도 가능한 범위에서 직접 스트림으로 읽으므로, 정상 작업 중에는 전체 사진을 이 폴더에 다시 저장하지 않습니다. 카드 리더기와 일반 폴더도 원본에서 대상으로 직접 읽고 씁니다.

- **캐시 폴더 열기**: 현재 설정된 임시파일 폴더를 파일 탐색기로 엽니다.
- **임시 파일 삭제**: FrameVault가 만든 카메라 임시 파일을 확인 후 삭제합니다.

진행 중인 백업이나 검사가 없을 때 삭제하십시오. 완료된 작업 뒤에 남은 임시 파일을 지워도 이미 백업된 대상 파일에는 영향이 없습니다. 이후 필요한 데이터는 연결된 카메라에서 다시 읽습니다.

## 13. 작업 취소와 안전한 분리

- 작업 중 **취소**를 누르면 현재 작업에 취소 요청을 보냅니다.
- 상태가 취소 또는 완료로 바뀔 때까지 카메라와 메모리카드를 분리하지 마십시오.
- 네트워크가 끊기면 연결을 복구한 뒤 같은 설정으로 다시 실행하십시오. 이미 정상적으로 존재하는 파일은 대조 후 건너뜁니다.
- 카메라 배터리가 충분한지 확인하고, 대용량 백업에는 안정적인 USB 케이블과 네트워크를 사용하십시오.

## 14. 지원 파일 형식

사진:

```text
JPG, JPEG, HEIC, NEF, ARW, CR2, CR3, RAF, ORF, RW2
```

영상:

```text
MP4, MOV
```

## 15. 문제 해결

### 카메라 또는 메모리카드를 찾지 못함

1. 카메라 전원을 켜고 잠금 화면이 있다면 해제합니다.
2. USB 케이블을 다시 연결하거나 다른 포트를 사용합니다.
3. 카메라의 USB 연결 모드를 PTP 또는 MTP로 바꿉니다.
4. 메모리카드에 `DCIM` 폴더와 지원 파일이 있는지 확인합니다.
5. **자동 탐색**을 다시 누릅니다.
6. 계속 찾지 못하면 **폴더 선택**으로 접근 가능한 원본 폴더를 직접 지정합니다.

충전 전용 USB 케이블은 데이터 통신을 지원하지 않습니다.

### `대상에 연결한 뒤 백업 폴더를 선택하세요`가 표시됨

SMB 또는 WebDAV의 루트, 계정 또는 비밀번호를 바꾸면 기존 폴더 선택이 초기화됩니다. 현재 정보를 입력한 뒤 **연결 후 폴더 선택**을 다시 눌러 저장할 폴더를 선택하십시오.

### 연결 시험 실패

- 로컬: 대상 폴더가 존재하고 쓰기 권한이 있는지 확인합니다.
- SMB: `\\서버\공유` 형식, 계정 권한, NAS의 SMB 설정과 방화벽을 확인합니다.
- WebDAV: HTTPS URL, 포트, 계정 권한과 인증서를 확인합니다.
- NAS가 절전 상태라면 완전히 깨어난 뒤 다시 시도합니다.

### 백업이 매우 느림

- **정밀 검증**은 원본과 대상을 다시 읽으므로 **표준 검증**보다 느립니다.
- WPD 카메라는 카드 리더기보다 전송 속도가 낮을 수 있습니다.
- 무선 네트워크보다 유선 LAN 또는 안정적인 Wi-Fi를 사용합니다.
- 카메라의 메모리카드를 고속 카드 리더기로 직접 연결하면 빨라질 수 있습니다.
- 전체 무결성 검사는 모든 파일을 읽으므로 백업할 새 파일이 없어도 시간이 걸립니다.

### WebDAV 최종 파일 이름 충돌

대상에 같은 경로와 이름을 가진 다른 내용의 파일이 있습니다. FrameVault는 기존 파일을 임의로 덮어쓰지 않습니다. NAS에서 두 파일을 확인한 뒤 기존 파일을 별도 위치로 옮기거나 이름을 변경하고 다시 백업하십시오.

### 카메라 정보 일부가 `N/A`로 표시됨

사진에 해당 MakerNote 또는 EXIF 값이 없거나 제조사별 형식을 해석할 수 없는 경우입니다. 다른 최신 JPG 또는 RAW 파일이 있는 원본으로 다시 확인해 보십시오.

### 다른 PC에서 프로필 비밀번호를 사용할 수 없음

비밀번호는 저장한 Windows 사용자 계정에 묶여 보호됩니다. 새 PC나 다른 사용자 계정에서는 대상 비밀번호를 다시 입력하고 프로필을 저장하십시오.

### 프로그램이 다른 PC에서 실행되지 않음

1. ZIP 내부에서 바로 실행하지 말고 전체 압축을 풉니다.
2. 최상위 `FrameVault.exe`와 `app` 폴더가 같은 위치에 있는지 확인합니다.
3. Windows 10 버전과 PC가 64비트인지 확인합니다.
4. 조직 보안 정책, SmartScreen 또는 Smart App Control의 차단 기록을 확인합니다.
5. 신뢰할 수 있는 배포본인지 확인하고 ZIP의 SHA-256 값이 배포자가 제공한 값과 일치하는지 확인합니다.

## 16. 권장 운영 방법

- 평소 백업은 **표준 검증**으로 빠르게 실행합니다.
- 중요한 촬영을 마친 뒤 또는 정기 점검 시 **전체 무결성 검사**를 실행합니다.
- 백업 대상 하나만 믿지 말고 중요한 사진은 서로 다른 물리 장치나 장소에 추가 사본을 유지합니다.
- 카메라나 카드의 파일은 백업 완료와 필요한 검증을 확인한 뒤 삭제합니다.
- 네트워크 백업 중에는 NAS와 PC가 절전 모드에 들어가지 않도록 설정합니다.

FrameVault는 카메라 제조사의 공식 프로그램이 아닙니다. 문서에 언급된 제품명과 상표는 각 소유자의 자산입니다.
