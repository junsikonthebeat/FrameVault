# FrameVault

FrameVault는 USB 카메라, 메모리카드 또는 사용자가 선택한 폴더의 사진과 영상을 Windows PC와 네트워크 저장소에 백업하는 프로그램입니다.

연결된 장치에서 지원되는 미디어 파일을 찾아 이전 백업 상태와 비교하고, 새 파일이나 대상에서 누락된 파일을 촬영 연도와 월에 따라 정리합니다. 빠른 크기 확인과 SHA-256 정밀 검증 중 필요한 방식을 선택할 수 있습니다.

처음 사용하는 경우 [FrameVault V1.0.0 사용 설명서](docs/FrameVault_사용설명서.md)를 먼저 확인하세요.

## 주요 기능

- USB로 연결된 WPD/MTP/PTP 카메라 탐색
- `DCIM` 폴더가 있는 메모리카드와 외장 저장장치 탐색
- 사용자가 선택한 일반 폴더를 원본으로 사용
- 프로그램 시작 시 장치 확인 및 실행 중 5초 간격의 새 장치 감지
- 새 장치 발견 시 사용할 백업 프로필을 선택해 바로 백업
- 로컬 폴더, SMB 공유 및 HTTPS WebDAV 저장소 지원
- 원격 저장소에 연결한 뒤 폴더 트리에서 백업 위치 선택
- 백업 대상과 검증 방식을 포함하는 프로필 최대 4개 저장
- 이전 백업 상태와 대상 파일을 비교하는 증분 백업
- 촬영일 기준 `연도/월` 폴더 자동 정리
- 시작일과 종료일을 이용한 촬영 기간 선택 백업
- 파일 크기를 확인하는 표준 검증
- 원본과 대상의 SHA-256을 비교하는 정밀 검증
- 원본과 백업 대상 전체의 누락·불일치 파일 검사
- 같은 경로에 내용이 다른 파일이 있을 때 충돌 알림
- 전송 진행률, 완료 파일 수 및 작업 취소
- 가장 최근 사진을 기준으로 한 카메라·렌즈 정보 조회
- 자동백업 임시파일 폴더 열기 및 정리
- 라이트 모드와 다크 모드

## 지원 파일

사진:

```text
JPG, JPEG, HEIC, NEF, ARW, CR2, CR3, RAF, ORF, RW2
```

영상:

```text
MP4, MOV
```

## 기본 사용 방법

1. 카메라나 메모리카드를 연결하고 `자동 탐색`을 실행하거나 원본 폴더를 선택합니다.
2. `로컬`, `SMB`, `WebDAV` 중 백업 대상을 선택합니다.
3. 네트워크 대상은 연결 정보를 입력한 뒤 폴더 트리에서 저장 위치를 선택합니다.
4. 자주 사용하는 백업 대상을 프로필로 저장합니다.
5. 필요한 경우 촬영 기간과 검증 방식을 설정합니다.
6. `새 파일 백업`을 실행합니다.
7. 기존 백업 전체를 확인하려면 `전체 무결성 검사`를 사용합니다.

프로그램은 촬영일을 기준으로 파일을 다음과 같이 정리합니다.

```text
선택한 백업 위치/
├─ 2025/
│  ├─ 01/
│  └─ 12/
└─ 2026/
   ├─ 01/
   └─ 10/
```

## 검증 방식

### 표준 검증

대상 파일의 존재 여부와 크기를 확인합니다. 빠른 일상 백업에 적합합니다.

### 정밀 검증

원본과 대상 파일의 SHA-256 값을 비교합니다. 대상 저장소의 기능과 네트워크 환경에 따라 표준 검증보다 오래 걸릴 수 있습니다.

### 전체 무결성 검사

선택한 원본과 백업 대상 전체를 비교해 누락되거나 내용이 일치하지 않는 파일을 표시합니다. 검사 자체는 대상 파일을 변경하지 않습니다.

## 카메라 정보

`카메라 정보`는 선택한 원본에서 가장 최근 사진을 찾아 사진에 기록된 메타데이터를 읽습니다.

- 최근 촬영 일시
- 총 셔터수
- 카메라 기종
- 시리얼 번호
- 카메라 바디 제조일자
- 렌즈 제조사
- 렌즈 모델명
- 렌즈 사양

카메라나 파일 형식에 해당 정보가 기록되지 않은 항목은 `N/A`로 표시됩니다.

## 저장 정보와 보안

- WebDAV는 HTTPS 연결을 사용합니다.
- 저장한 네트워크 접속 정보는 현재 Windows 사용자 범위에서 보호됩니다.
- 다른 Windows 사용자나 다른 PC에서는 저장된 접속 정보를 다시 입력해야 할 수 있습니다.
- 백업 작업은 사용자가 선택한 원본과 대상에 대해 수행됩니다.

## 포터블 버전

배포 ZIP을 완전히 압축 해제한 뒤 최상위의 `FrameVault.exe`를 실행합니다.

```text
FrameVault.exe
app/
docs/
```

`app` 폴더는 프로그램 실행에 필요한 파일을 포함하므로 이동하거나 일부 파일을 삭제하면 안 됩니다.

### 배포 ZIP 만들기

Visual Studio 2026이 설치된 개발 PC에서 다음 명령을 실행합니다.

```powershell
.\build-framevault.ps1 -Version 1.0.0
```

스크립트는 네트워크 작업 폴더의 파일 잠금을 피하기 위해 로컬 임시 폴더에서 빌드하며,
`App.xbf`, `MainWindow.xbf`, `FrameVault.pri`, `resources.pri`가 모두 생성됐는지 확인한 뒤 ZIP을 만듭니다.

## 시스템 요구사항

- 64비트 Intel 또는 AMD 기반 PC
- Windows 10 버전 1809 이상 또는 Windows 11
- 원본 및 백업 대상에 대한 읽기·쓰기 권한
- 네트워크 백업 사용 시 해당 저장소에 연결할 수 있는 네트워크 환경

## 제한 사항

- USB 카메라 인식과 파일 접근 가능 여부는 카메라의 연결 모드, Windows 드라이버 및 제조사 구현에 따라 달라질 수 있습니다.
- 일부 카메라는 USB 연결 모드를 PTP 또는 MTP로 설정해야 합니다.
- 카메라 정보는 사진에 실제로 기록된 메타데이터 범위에서만 표시됩니다.
- 저장소 종류와 서버 설정에 따라 정밀 검증 시간이 길어질 수 있습니다.
- 현재 포터블 배포본은 공인 코드 서명이 없어 Windows의 앱 보호 기능이 실행을 차단할 수 있습니다.

FrameVault는 카메라 제조사의 공식 프로그램이 아닙니다. 문서에 언급된 제품명과 상표는 각 소유자의 자산입니다.
